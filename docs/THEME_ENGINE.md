# Theme Engine — how any movie gets its own auditorium

Dune, Godzilla and Avengers: Doomsday were only the *reference looks* from the brief. The engine has no
per-title rules: it reads whatever a listing knows about a film and designs the hall from that. Code:
`backend/app/services/theme_engine.py` (logic) and `theme_lexicon.py` (data).

## 1. Evidence

| Source | Weight per matched word | Example |
|---|---|---|
| Genres (every TMDB genre + Indian labels) | prior per archetype, × 1.0 / 0.8 / 0.65 … by position | `Crime` → noir 1.8, underworld 1.4 |
| Title | 2.5 | "**Frost**line" → frost |
| Tagline + synopsis | 1.2 (max 5 words per archetype) | "red **sandalwood** **smuggler**" → underworld |
| TMDB keywords | 2.0 | `kaiju`, `desert planet` |
| Mood tags (admin) | 3.0, +6 if the tag *is* an archetype name | `neon` |
| A past decade in the text | 1.2 to period | "in the 1920s" |
| Colour words in the text | hue pull, ≤ 2.5 | "**pink** doll world" → pop |
| Poster colours | hue pull by share of the image, ≤ 2.5 | 55 % `#ff3fa4` → pop / romance |

Words are lower-cased, plural-folded (`monsters` → `monster`, `cities` → `city`) and paired into bigrams, so
the lexicon can hold phrases like `deep_sea` or `red_sandalwood`. No NLP library, no network call — it runs
in well under a millisecond per movie.

## 2. Archetypes

27 visual families, each a palette (primary light, deep wash, accent), particles, ambience sound, fog and
pulse: desert, wasteland, ocean, sky, cosmic, tech, neon, horror, inferno, frost, jungle, noir, underworld,
kinetic, suspense, romance, pop, whimsy, sunny, stage, royal, mythic, battlefield, period, intimate, arena.

The top archetype wins. The runner-up is blended in **in proportion to its score** (if it reaches 45 % of the
winner), so Pushpa 2 is "underworld with a touch of kinetic", not a coin flip between the two.

## 3. Colour

1. Archetype palette (blended).
2. Poster colours, if any: `palette.py` quantises the image (median cut on a 128 px thumbnail), merges near
   duplicates, and `art_roles()` picks the most vivid large colour as the primary light, the most different
   vivid colour as the accent, and the darkest substantial colour as the deep wash.
3. Admin hex picks (`palette_hint`) on top — a human always has the last word.
4. **Signature**: a stable ±12° hue drift and a small fog/pulse wobble from the title hash, so two crime
   thrillers with identical metadata still get different halls. Drift shrinks to 30 % when the colours came
   from real artwork.

No evidence at all (an experimental film with no genres)? The title hash alone produces a harmonious palette.

## 4. Safety (`guard`)

Backgrounds stay dark, light colours stay bright, ambient light can't drop so low that back rows vanish, fog
and particles are capped for phones, unknown particle/sound presets fall back, NaN and garbage are rejected.
Seat status colours are never part of a theme, so availability reads the same in every hall.

## 5. Explain

Every auto theme ships with `explain`:

  "confidence": 0.72,

  "signature_shift_deg": -11.2,
  "signals": [
    {"archetype": "underworld", "label": "Underworld", "score": 6.28,
     "evidence": ["genre Crime", "story 'empire'", "story 'red sandalwood'", "story 'sandalwood'",

## 7. Getting real movies in

* **TMDB import** (admin → Movies): search, click Import. Genres, keywords, cast, trailer, Indian certificate
  and the poster's colours come in; the theme is ready immediately. Needs `CV_TMDB_API_KEY` or
  `CV_TMDB_READ_TOKEN`. This product uses the TMDB API but is not endorsed or certified by TMDB.
* **By hand**: title + genres + a line of synopsis is enough. Upload key art to pull its colours — the image is
  dropped unless you tick "I have the rights to display this image".
* **Theme Lab** (`/lab`): anyone can type any film (and optionally drop a poster) to see the hall it would get.
  Nothing is saved.

## 8. Tuning

Add or retune a look in `theme_lexicon.py` only. `tests/test_theme_engine.py` holds 16 real films with the
family each must land in, a check that every TMDB genre is understood, and a check that every film gets a
distinct palette — run it after any change.
